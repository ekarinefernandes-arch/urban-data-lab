# 🌍 Urban Data Lab

Urban Data Lab é um projeto em Python voltado para análise de dados urbanos, integração de bases públicas e apoio à tomada de decisão em planejamento urbano.

## Objetivo

Construir uma plataforma capaz de integrar:

- 📊 Dados do IBGE
- 🏘️ Mercado imobiliário
- 🗺️ Geoprocessamento
- 📍 Geocodificação
- 📈 Estatística espacial
- 🌎 Geração automática de mapas
- 📄 Exportação para QGIS

## Tecnologias

- Python
- Pandas
- Requests
- Git
- GitHub
